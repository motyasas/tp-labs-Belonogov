# Лабораторная работа 7 — модульное приложение «Банк»

## Структура решения

```
Lab7/
├── Lab7.slnx
├── BankSystem.Core/    ← библиотека: счета, банк, журнал операций (НЕТ Console)
├── BankSystem.App/     ← консольное меню (ссылается на Core, NuGet ConsoleTables)
└── BankSystem.Tests/   ← xUnit-тесты (ссылаются на Core)
```

## Схема зависимостей (бонус)

```
BankSystem.App ──────► BankSystem.Core ◄────── BankSystem.Tests
      │
      └──► ConsoleTables (NuGet)
```

- `App → Core` допустима: интерфейс пользователя использует логику.
- `Core → App` невозможна: получилась бы циклическая ссылка (App уже ссылается на Core),
  а .NET не разрешает циклические ссылки между проектами. Кроме того, логике незачем знать,
  как её показывают пользователю — поэтому Core можно подключить к окну, сайту или тестам без изменений.

## Интерфейс-контракт

`ITransactionLog` — журнал операций банка. Две реализации:

| Класс | Где хранит записи | Для чего |
|---|---|---|
| `FileTransactionLog` | в файле `bank_log.txt` | обычная работа программы |
| `MemoryTransactionLog` | в списке в памяти | тесты (не создаёт файлов) |

Реализация передаётся в конструктор `Bank(name, log)` — внедрение зависимости.

## Запуск

```
dotnet build
dotnet test
dotnet run --project BankSystem.App
```
